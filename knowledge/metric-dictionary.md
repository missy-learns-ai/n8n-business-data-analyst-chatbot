# Metric Dictionary

This dictionary defines the approved metrics available to the analytics workflow.

The metric keys must match the `metric_registry.metric_key` values in Supabase. The formulas are trusted SQL snippets used inside controlled query templates. Users must not provide or override formulas directly.

## Ecommerce Metrics

Dataset: `ecommerce_orders`

| Metric key | Display name | Formula | Business definition | Format |
|---|---|---|---|---|
| `order_count` | Order Count | `COUNT(*)` | Total number of ecommerce orders. | Integer |
| `gross_sales` | Gross Sales | `SUM(quantity * unit_price)` | Total sales before discounts are removed. | Currency |
| `net_sales` | Net Sales | `SUM((quantity * unit_price) - ((quantity * unit_price) * discount_percent / 100))` | Sales after discounts are removed. | Currency |
| `return_rate` | Return Rate | `COUNT(*) FILTER (WHERE order_status = 'Returned')::numeric / NULLIF(COUNT(*), 0)` | Share of orders with Returned status. | Ratio |
| `average_rating` | Average Rating | `AVG(rating)` | Average customer rating across ecommerce orders. | Decimal |
| `average_delivery_days` | Average Delivery Days | `AVG(delivery_days)` | Average number of days between order and delivery. | Decimal |

### Ecommerce Interpretation Notes

- Use `net_sales` as the default sales metric when the user asks for sales without specifying gross or net.
- Use `gross_sales` only when the user explicitly asks for sales before discounts or gross sales.
- `return_rate` is a ratio. A value of `0.11` means 11 percent of orders in the selected slice were returned.
- `average_rating` should be interpreted only across records where the source data includes ratings.
- `average_delivery_days` is directional. Lower values are usually better.

### Ecommerce Caveats

- The current ecommerce table does not include product cost, so profit metrics are not supported.
- The current ecommerce table does not include inventory, margin, customer lifetime value, or refund amount.
- Shipping cost exists in the source table but is not part of the approved sales formulas.

## Marketing Metrics

Dataset: `marketing_campaigns`

| Metric key | Display name | Formula | Business definition | Format |
|---|---|---|---|---|
| `spend` | Spend | `SUM(spend)` | Total marketing campaign spend. | Currency |
| `impressions` | Impressions | `SUM(impressions)` | Total number of ad impressions. | Integer |
| `clicks` | Clicks | `SUM(clicks)` | Total number of ad clicks. | Integer |
| `conversions` | Conversions | `SUM(conversions)` | Total number of campaign conversions. | Integer |
| `revenue` | Revenue | `SUM(revenue)` | Total revenue attributed to marketing campaigns. | Currency |
| `leads` | Leads | `SUM(leads)` | Total number of leads generated by marketing campaigns. | Integer |
| `new_customers` | New Customers | `SUM(new_customers)` | Total number of new customers acquired through marketing campaigns. | Integer |
| `ctr` | Click Through Rate | `SUM(clicks)::numeric / NULLIF(SUM(impressions), 0)` | Share of impressions that became clicks. | Ratio |
| `conversion_rate` | Conversion Rate | `SUM(conversions)::numeric / NULLIF(SUM(clicks), 0)` | Share of clicks that became conversions. | Ratio |
| `cost_per_click` | Cost Per Click | `SUM(spend)::numeric / NULLIF(SUM(clicks), 0)` | Average marketing spend per click. | Currency |
| `cost_per_conversion` | Cost Per Conversion | `SUM(spend)::numeric / NULLIF(SUM(conversions), 0)` | Average marketing spend per conversion. | Currency |
| `roas` | ROAS | `SUM(revenue)::numeric / NULLIF(SUM(spend), 0)` | Revenue generated per dollar of ad spend. | Decimal |
| `revenue_per_click` | Revenue Per Click | `SUM(revenue)::numeric / NULLIF(SUM(clicks), 0)` | Average revenue generated per click. | Currency |
| `lead_to_customer_rate` | Lead To Customer Rate | `SUM(new_customers)::numeric / NULLIF(SUM(leads), 0)` | Share of leads that became new customers. | Ratio |

### Marketing Interpretation Notes

- Use `roas` when the user asks about return on ad spend, ad efficiency, or revenue generated per spend.
- Use `conversion_rate` when the user asks how effectively clicks become conversions.
- Use `ctr` when the user asks how effectively impressions become clicks.
- Use `cost_per_click` and `cost_per_conversion` for cost-efficiency questions.
- Use `lead_to_customer_rate` when the user asks how effectively leads become customers.

### Marketing Caveats

- Revenue is campaign-attributed revenue in the sample dataset, not audited finance revenue.
- The current marketing table does not include organic traffic, customer acquisition cost by cohort, retention, or lifetime value.
- Ratio metrics use `NULLIF` to prevent division by zero. If a denominator is zero, the metric can return no value and must be disclosed as a warning.

## Metric Selection Rules

- Sales questions in ecommerce default to `net_sales`.
- Sales questions in marketing map to `revenue` unless the user asks for spend or cost.
- Performance questions should use the most specific metric available. For example, "best ad return" maps to `roas`, while "best conversion performance" maps to `conversion_rate`.
- If the requested metric is not in this dictionary, the workflow should ask for clarification or return a controlled unsupported response.
